## Проверки

- CI run: https://github.com/Partner-money/Treker/actions/runs/40362035668 — success (7/7 инструментальных тестов, 0 падений). Сборка и тесты занимают около 10 минут на образе `aosp_atd`.
- Шаги: JDK 17, Android SDK 35, `testDebugUnitTest`, `assembleDebug`, `connectedDebugAndroidTest` на лёгком эмуляторе `aosp_atd` API 30.
- APK: артефакт `treker-debug-apk` в этом run. В контейнере скачивание артефакта заблокировано сетевой политикой, файл доступен через веб-интерфейс GitHub.

## Этап 9 — кандидаты на следующую итерацию

1. Звуки: выбор пользовательского файла, отдельные сигналы для напоминаний и завершения таймера, предпрослушивание, отключение звука.
2. Настройки поведения: первый день недели, формат времени, поведение при пропуске, порог «частично выполнено», автостарт следующего дня.
3. Ручная проверка на устройстве: установка APK, напоминания после перезагрузки, таймер в фоне, Samsung/Xiaomi.

## Ограничения и оставшиеся риски

Локально в контейнере нет JDK и Android SDK, поэтому все проверки выполняются через GitHub Actions. Автотесты не покрывают доставку напоминаний, работу таймера в фоне после сна устройства и реальные производители (Samsung/Xiaomi). Эти сценарии требуют ручной проверки на физических устройствах.
