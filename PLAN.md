# План реализации Treker

Статус проверен по ТЗ. Этапы 1–9 приняты; этап 10 (начало нового дня, отображение прогресса, тесты миграций) реализован и проверен в CI, ожидает приёмки. Цель дальнейшей работы — ручная проверка на устройствах и оставшиеся продуктовые пробелы.

## Проверки

- CI run: https://github.com/Partner-money/Treker/actions/runs/40362035668 — сборка и 7 тестов этапа 8.
- CI run: https://github.com/Partner-money/Treker/actions/runs/40378491410 — этап 10: юнит-тесты и 17 инструментальных тестов, 0 падений.
- CI run: https://github.com/Partner-money/Treker/actions/runs/40640725440 — этап 11: юнит-тесты и 28 инструментальных тестов, 0 падений.
- CI run: https://github.com/Partner-money/Treker/actions/runs/40684690890 — этап 12: юнит-тесты, 32 инструментальных теста и проверка экспортированной схемы, 0 падений.
- Шаги: JDK 17, Android SDK 35, `testDebugUnitTest`, `assembleDebug`, `connectedDebugAndroidTest` на лёгком эмуляторе `aosp_atd` API 30.
- APK: артефакт `treker-debug-apk` в том же run.
- Тест миграций применяет настоящие объекты `MIGRATION_1_2` и `MIGRATION_2_3` к базе со старой схемой и данными; схема Room в репозиторий не выгружена, поэтому тест не сверяет identity hash.
- `RoomSchemaCompatibilityTest` открывает реальный `AppDatabase` поверх базы версии 1: Room сам сверяет колонки, индексы и внешние ключи с сущностями. Этот тест уже нашёл неполную тестовую схему (пропущенные внешний ключ и уникальный индекс `daily_records`) — теперь схема v1 вынесена в общий `LegacySchema`.
- `RoomSchemaAssetTest` сравнивает identityHash из экспортированной схемы с hash в `room_master_table` реально созданной базы: ловит изменение сущностей без поднятия версии и поднятие версии без переэкспорта схемы.
- Штатный `MigrationTestHelper` пока не используется: ему нужны схемы всех версий в assets, а схема версии 1 в проекте никогда не экспортировалась и восстановить её генерацией нельзя. Схемы публикуются артефактом `room-schema`; после коммита файлов версий 1–3 тест можно перевести на helper без изменения проверок.
- Run 40371238609 упал на инфраструктуре: adb увидел устройство как несовместимое до запуска тестов. Шаг эмулятора теперь перезапускает adb-сервер и ждёт устройство; проверка повторена. В контейнере скачивание артефакта заблокировано сетевой политикой, файл доступен через веб-интерфейс GitHub.

## Этап 13 — кандидаты на следующую итерацию

1. UI-тесты счётчика, таймера и экрана настроек (сейчас сквозной сценарий покрывает простую привычку).
2. Закоммитить схемы Room версий 1–3 из артефакта `room-schema` и перевести тест миграций на штатный `MigrationTestHelper`.
3. Ручная проверка на физических устройствах: установка APK, звук в беззвучном режиме, напоминания после перезагрузки, таймер в фоне, Samsung One UI и Xiaomi.

## Ограничения и оставшиеся риски

Локально в контейнере нет JDK и Android SDK, поэтому все проверки выполняются через GitHub Actions. Автотесты не покрывают доставку напоминаний, работу таймера в фоне после сна устройства и реальные производители (Samsung/Xiaomi). Эти сценарии требуют ручной проверки на физических устройствах.
