# План реализации Treker

Статус проверен по ТЗ после первого прохода. Цель — завершить продуктовые сценарии, а не считать наличие экранов критерием готовности.

| Область | Статус | Следующий проверяемый результат |
|---|---|---|
| Проект, навигация, Compose / Material 3 | Частично реализовано; сборка не запускалась | Успешная Android-сборка и ручная проверка на устройстве |
| Room: привычки, расписания, дневные снимки, синхронизация | Реализовано базовое ядро | Тесты транзакций, повторного открытия дня и изменения целей |
| Простое действие / счётчик / таймер / накопление времени | Реализовано базово | UI и интеграционные тесты, проверка фонового таймера на Android |
| Раздел «Сегодня», фильтры, прошедшие даты | Реализовано базово | Проверить сценарии изменения с обоих экранов и восстановление истории |
| Встроенные шаблоны | Реализованы | Проверить добавление шаблона в рабочий план |
| Пользовательские шаблоны | Реализовано, не проверено сборкой | Ручная проверка сохранения из меню, повторного создания, удаления, миграции Room 1→2 и JSON v2 |
| Прогресс, тепловая карта, серии, периоды | Частично реализовано; добавлен раскрываемый дневной журнал привычки | Уточнить календарные границы и протестировать статистику на реальных расписаниях |
| Напоминания / таймерные уведомления | Реализован базовый AlarmManager путь | Установочная и фоновая проверка на Android 8–15 и Samsung One UI; доставка может задерживаться ОС |
| Настройки темы / уведомлений / данных | Частично реализовано: 3 темы, 6 акцентов, произвольная категория и глобальные переключатели | Добавить управление звуковыми файлами/предпрослушиванием и настройки поведения |
| JSON-резервная копия | Формат версии 2 включает привычки, записи, собственные шаблоны и основные настройки; импорт версии 1 поддержан; не проверено сборкой | Тесты валидного, повреждённого и повторно импортированного файла |
| Автоматические тесты | Добавлены unit-тесты логики и Android-тесты Room / backup / UI smoke; не запускались | Запустить `testDebugUnitTest connectedDebugAndroidTest` на CI и исправить найденные сбои |
| APK и GitHub Actions | Wrapper и workflow настроены для тестов на API 35 и сборки, APK пока не собран | Получить успешный CI run и загрузить устанавливаемый APK как артефакт |

## Ограничения среды

В текущем контейнере отсутствуют Java/JDK и Android SDK. Проверены синтаксис Kotlin, XML, YAML и Gradle wrapper; компиляция, тесты, UI и APK остаются непроверенными. Не считать задачу завершённой, пока CI/Android-среда не подтвердит сборку и критические сценарии.
