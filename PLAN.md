## Проверки

- CI run: https://github.com/Partner-money/Treker/actions/runs/40362035668 — сборка и 7 тестов этапа 8.
- CI run: https://github.com/Partner-money/Treker/actions/runs/40368998887 — этап 9: юнит-тесты и 14 инструментальных тестов, 0 падений.
- Шаги: JDK 17, Android SDK 35, `testDebugUnitTest`, `assembleDebug`, `connectedDebugAndroidTest` на лёгком эмуляторе `aosp_atd` API 30.
- APK: артефакт `treker-debug-apk` в том же run.
- Run 40371238609 упал на инфраструктуре: adb увидел устройство как несовместимое до запуска тестов. Шаг эмулятора теперь перезапускает adb-сервер и ждёт устройство; проверка повторена. В контейнере скачивание артефакта заблокировано сетевой политикой, файл доступен через веб-интерфейс GitHub.

## Этап 10 — кандидаты на следующую итерацию

1. Начало нового дня: настраиваемый час смены даты вместо фиксированных 00:00.
2. Миграция Room 2→3: автоматический тест миграции (нужна выгрузка схемы Room в репозиторий).
3. Ручная проверка на устройстве: установка APK, звук в беззвучном режиме, напоминания после перезагрузки, таймер в фоне, Samsung/Xiaomi.

## Ограничения и оставшиеся риски

Локально в контейнере нет JDK и Android SDK, поэтому все проверки выполняются через GitHub Actions. Автотесты не покрывают доставку напоминаний, работу таймера в фоне после сна устройства и реальные производители (Samsung/Xiaomi). Эти сценарии требуют ручной проверки на физических устройствах.
