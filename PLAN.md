# План реализации Treker

Статус проверен по ТЗ. Этапы 1–8 приняты: сборка, unit-тесты и инструментальные тесты на эмуляторе проходят в CI. Цель дальнейшей работы — закрыть продуктовые пробелы, а не считать наличие экранов критерием готовности.

| Область | Статус | Следующий проверяемый результат |
|---|---|---|
| Проект, навигация, Compose / Material 3 | Сборка и запуск главного экрана подтверждены CI на эмуляторе API 34 | Ручная проверка на физическом устройстве |
| Room: привычки, расписания, дневные снимки, синхронизация | Ядро реализовано; тесты идемпотентности дня и счётчика проходят в CI | Проверить изменение целей у уже выполненных записей вручную |
| Простое действие / счётчик / таймер / накопление времени | Реализовано базово | UI и интеграционные тесты, проверка фонового таймера на Android |
| Раздел «Сегодня», фильтры, прошедшие даты | Реализовано базово | Проверить сценарии изменения с обоих экранов и восстановление истории |

| Напоминания / таймерные уведомления | Реализован базовый AlarmManager путь | Установочная и фоновая проверка на Android 8–15 и Samsung One UI; доставка может задерживаться ОС |

| APK и GitHub Actions | CI зелёный, debug APK собран и опубликован артефактом `treker-debug-apk` в run 40347718986 | Скачать APK через веб-интерфейс Actions и проверить установку на устройстве |

## Проверки

- CI run: https://github.com/Partner-money/Treker/actions/runs/40347718986 — success.
- Шаги: JDK 17, Android SDK 35, `testDebugUnitTest`, `assembleDebug`, `connectedDebugAndroidTest` на эмуляторе API 34.
- APK: артефакт `treker-debug-apk` в этом run. В контейнере скачивание артефакта заблокировано сетевой политикой, файл доступен через веб-интерфейс GitHub.

## Ограничения и оставшиеся риски

Локально в контейнере нет JDK и Android SDK, поэтому все проверки выполняются через GitHub Actions. Автотесты не покрывают доставку напоминаний, работу таймера в фоне после сна устройства и реальные производители (Samsung/Xiaomi). Эти сценарии требуют ручной проверки на физических устройствах.
